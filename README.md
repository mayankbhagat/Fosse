# Chemical Equipment Parameter Visualizer

A full-stack, hybrid application extending across Web and Desktop platforms to visualize chemical equipment data. Built as an intern screening task prototype.

## 🚀 Features

*   **Multi-Platform**:
    *   **Web Dashboard**: React + Tailwind + Chart.js (Modern, Responsive).
    *   **Desktop App**: PyQt5 + Matplotlib (Native, integrated with backend).
*   **Backend**: Django REST Framework (DRF) serving a unified API.
*   **Analytics**: Pandas-powered statistical summaries of Flowrate, Pressure, and Temperature.
*   **Reporting**: Automated PDF generation for upload batches.
*   **Security**: Token-based authentication.

## 🛠 Setup Instructions

### Prerequisites
*   Python 3.10+
*   Node.js 18+

### 1. Backend (Django)

```bash
cd backend
python -m venv venv
# Windows
.\venv\Scripts\activate
# Install Requirements
pip install django djangorestframework pandas django-cors-headers reportlab
# Run Migrations
python manage.py migrate
# Create Admin (if not exists)
# python manage.py createsuperuser
# Run Server
python manage.py runserver
```
*API runs at `http://127.0.0.1:8000/api/`*

### 2. Web Frontend (React)

```bash
cd web-frontend
npm install
npm run dev
```
*App runs at `http://localhost:5173/`*
*Login with `admin` / `password123`*

### 3. Desktop App (PyQt5)

```bash
cd desktop-app
# Ensure backend venv is active or install dependencies
pip install PyQt5 matplotlib requests
python main.py
```
*Native window will open. Login with `admin` / `password123`.*

## 📡 API Endpoints

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `POST` | `/api/login/` | Get Auth Token |
| `POST` | `/api/upload/` | Upload CSV File |
| `GET` | `/api/statistics/` | Get Stats for latest upload |
| `GET` | `/api/statistics/<id>/` | Get Stats for specific upload |
| `GET` | `/api/history/` | List recent uploads |
| `GET` | `/api/report/<id>/` | Download PDF Report |

## 🎨 Design Decisions

*   **Consistency**: Both Web and Desktop apps share the same "Chemical Teal" color palette (`#0284c7`) and Dark Slate backgrounds.
*   **Scalability**: The Backend is the single source of truth. Clients (Web/Desktop) are just views.
*   **Performance**: Pandas handles heavy CSV processing efficiently.
